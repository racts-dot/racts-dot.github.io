The eight things the store wants

Six are wording, below, with a copy button each. Two are yours alone — the contact email and verifying it — because they need your inbox.

1 · Single purpose description

Privacy practices tab

Start replaces Chrome's new tab with one personal start page: a clock, a single line for what the user wants to finish today, a private scratch pad, and a set of links to the sites the user already works in.

2 · Justification for host permission use

Privacy practices tab · covers both permissions

The extension reads four small JSON files from the user's own website, racts-dot.github.io, to display the day's progress, the decisions waiting on the user, and the user's own list of links. It also reads and writes one note through the user's own relay at apps-notion-relay.workers.dev, so the scratch pad shows the same text on each of the user's computers. Both addresses belong to the user. No other site is contacted, and nothing is sent to any third party.

3 · Justification for remote code use

Privacy practices tab

This extension does not execute remote code. Every HTML, CSS and JavaScript file it runs is contained in the uploaded package. The only network requests retrieve JSON data files and the user's own saved note. No script is loaded, injected or evaluated from a remote source, and no eval of fetched content takes place.

If there is a yes/no question above this box asking whether the extension uses remote code, the honest answer is No — that is what the package was rebuilt to achieve. Paste this only if it still demands text.

4 · Detailed description

Store listing tab · needs 25 characters or more

Start replaces the new tab with a calm page: a large clock, a greeting, and one line for the single thing you want to finish today.

Everything else stays out of the way behind one small button in the corner. Press it, or the D key, and you get the day's progress, anything waiting on your decision, and a grid of links to the places you work, with a search box to filter them.

A scratch pad sits in that panel and is shared between your own computers through your own Notion workspace, so a note typed on one machine is already there on the next. If two machines disagree it asks you rather than overwriting what you typed.

Nothing is collected and nothing is tracked. The page reads only the data files on your own website and your own relay.

6 · Data usage certification

Privacy practices tab · three tick boxes

  1. Not being sold to third parties — tick
  2. Not being used or transferred for purposes unrelated to the single purpose — tick
  3. Not being used to determine creditworthiness or for lending — tick

All three are true of this package: it sends nothing anywhere except your own two addresses.

7 and 8 · Yours, because they need your inbox

Settings page

  1. Enter a publisher contact email.
  2. Press verify, then open the email Google sends and click its link.

Nobody can do this for you, and until it is done the Publish button stays refused however complete everything else is.

One more setting before you press publish: Visibility → Unlisted, so it never appears in search and only a link reaches it. It still installs and syncs across your own computers.
