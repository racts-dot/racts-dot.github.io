RECIPE 01 — Build an AI social media manager in Claude Code

**From: Claude Code Is Revolutionizing Marketing and Social Media · 11 Feb 2026 · 20:09 ·** watch

I read the whole transcript and wrote this so you can follow it. Her words are in quotes and unchanged.

What this gets you

A /social-media-post command. You type a topic, it writes the post in your brand voice for several platforms, shows you a draft, and only posts once you approve.

"How to build an AI social media manager with Claude Code skills in 10 minutes. You don't need any technical background whatsoever."

⚠ Read this before you start — two honest warnings

⛔ Blotato is HER OWN product. She built it. So this tutorial is partly a demo of her own app, and the API key is a paid feature — her words: "Note that this is a paid feature uh that helps me reduce kind of low-quality content being posted."

⛔ The example she uses is a realtor, not a printables seller. Everything works the same, but every answer you give will be different from hers.

⭐ The genuinely reusable part is Step 5, and it costs nothing.

THE STEPS

1 · Install VS Code

code.visualstudio.com — "100% free. Download it."

2 · Install the Claude Code extension

Left sidebar → Extensions → search Claude → "The first item on the list, which has over 4 million downloads."

You should see: an orange icon, top right.

3 · Sign in

Click the orange icon. First time, it walks you through authentication.

4 · Make a folder for the project

Hers is called AI-Social-Media-Manager. Any name. It just needs its own folder.

5 · ⭐ Paste this prompt — her wording, unchanged

"Create a new Claude skill, an AI social media manager that knows my brand voice and makes social media posts for these platforms. [your platforms here] We're going to use the blot API to handle publishing to social media and creating visuals such as infographic, carousels, slideshows, and videos. [link the API docs for posting] [link the API docs for creating visuals] We're going to maintain a separate file with all of our published posts and their URLs so we can always go back and reference them. And at the very end, ask me clarifying questions one at a time until you're 95% confident you can complete the task successfully."

⭐⭐ The bit worth stealing, whatever you are building

"ask me clarifying questions one at a time until you're 95% confident"

Her reason: "If you don't say one at a time, it's going to give you that list of 12 questions all at once. And it's just a lot to sit down and do all at once."

⭐ This works on any prompt, in any tool, for free. It is the single most portable thing in the video — and it is the same 95% rule you already have in your own settings.

6 · Answer its questions

It asks about brand voice, tone, your audience, your catchphrases, your handle, your call-to-action.

⚠ Push back if it asks for account IDs. Her words: "if claude does ask you for account ids and page ids and stuff push back a little because it can actually fetch all of that information automatically."

Answers she recommends:

QuestionHer answerWhy
Publish or draft?"draft first always""it is important to maintain high quality content"
One post or one per platform?"one unified post with platform specific tweaks"
Generate a visual every time?"ask me each time"sometimes you want your own image
Post log format?markdown table"nice and visual"

7 · The API key — do it the safe way

It will tell you to run export. Don't.

"for safety reasons and because you don't want to do that every time... it's just better practice to create a [.env] file which is like an environment file locally that will store your API key"

Just ask Claude: "create local .env file for API key" — then paste the key in and save.

8 · Test it

Type /social-media-post and a topic.

⭐ Or just describe what you want — "oftentimes Claude can infer from your prompt if it should use a skill or not."

9 · Fix the voice by talking to it

If the draft is too stiff: "update the drafts and update my brand voice ... to use a few emojis to sound a little more friendly."

"it will be applied if you try to create other social media posts"

It edits its own instructions permanently. You can also open the file and edit by hand.

⭐ What a "skill" actually is, in her words

"you can think of a cloud code skill as like a reusable piece of code and context. So instead of having to tell it every time like these are the guidelines for my brand... it's all encoded in this skill."

The file it makes is social-media-post.md and it is plain text you can edit.

What to try it on first

Don't build the whole thing. Do Step 5 only, on something small:

   Take any job you'd normally hand Claude
        │
   add: "ask me clarifying questions one at a
        time until you're 95% confident"
        │
   see how different the result is

That costs nothing, needs no Blotato, and tests the one idea that transfers.
