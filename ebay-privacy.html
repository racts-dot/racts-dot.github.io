Privacy Policy

Rachierachies7 eBay AU Tools · last updated 11 September 2026

In one line: this is a private tool used by one person to read her own eBay seller account. It has no other users, it collects nothing from anybody else, and it sends no data to any third party.

Who this application is for

Rachierachies7 eBay AU Tools is a personal application built and used solely by the owner of the eBay seller account it connects to. It is not offered to the public, has no sign-up, and no other person can connect an eBay account to it.

What information it accesses

When the account owner signs in through eBay and grants consent, the application may read, from that owner's own eBay account:

  • orders and sales history
  • listings and inventory
  • publicly available eBay listing and price information

It does not request, receive, or store any eBay password. eBay never shares passwords with applications.

How that information is stored

All information retrieved from eBay is stored only on the account owner's own computer, in files readable only by that computer's user account. Nothing is uploaded to a website, a database, a cloud service, or any server operated by this application or by anybody else.

The access tokens issued by eBay are stored in the same way, on that computer only, and are used solely to make requests to eBay's own API.

What is not done with it

  • It is not sold, rented, licensed, or shared with any third party.
  • It is not used for advertising, profiling, or marketing of any kind.
  • It is not combined with data from other people, because there is no other person using this application.

Other people's data

Where the application reads publicly available eBay listings for price research, it reads only what eBay already publishes to any visitor. That information is used to compare prices, is not stored beyond the immediate task, and is never republished.

Keeping information

Retrieved information is kept only as long as it is useful to the account owner and is deleted by deleting the files on that computer. eBay access can be withdrawn at any time from the account owner's own eBay account settings, which immediately stops this application from reading anything further.

Security

All connections to eBay use encrypted HTTPS. Credentials are held in files restricted to the owner's user account and are excluded from any code repository, so they are never published or backed up to a shared location.

Children

This application is not directed at children and collects no information from anybody other than its single owner.

Changes to this policy

If the way the application handles information changes, this page will be updated and the date at the top will change with it.

Contact

Questions about this policy can be sent to the eBay registered account holder for the seller account rachierachies7, through eBay's own messaging.

This page exists because eBay's Developers Program requires every application to publish a privacy policy at a secure address. It describes a single-user personal tool and nothing more.
