**Both tools let Claude write a video as code, then record it to an MP4 on your own computer. No credits, only plan tokens. They are good at moving text, charts and screenshots. They are also good at drawing a product that does not exist, which is the part you must never use.**

# ⭐⭐ THE ONE THING — the video frames the real pages, it never redraws them

Her promise is simple. You describe a video, Claude codes it, and a free tool records it.

> "it's actually coding a website like using HTML, CSS, and JavaScript and then it's like animating that website and recording it" ([5:30](https://www.youtube.com/watch?v=ncpA7rRk2Is&t=330s))

That makes it a promo tool, not an art tool. For you it splits in two:

```
ALLOWED (promotion)                 ⛔ NEVER (stands in for the product)
───────────────────                 ────────────────────────────────────
animated title, hook, price          a "simulated" page drawn by code
real page images, zoomed, panned     charts or covers invented to look
a real page count, a real list         like what the buyer gets
captions, a closing call to action   anything that "looks better than
                                       my actual product"
```

The rule for every video: each product page shown is a PNG rendered from the real PDF, placed in the folder as a media file. The code may move it, crop it and frame it. It may not draw it.

## Why this matters to you

On 12 Sep you had 46 live listings, zero sales, and a #2 rank on Etsy AU for "dementia caregiver binder". People can find you. What happens after they see a listing is the unproven part. A short video that shows the actual pages is one way to show a buyer what they get. A video that shows pages you did not make is a refund waiting to happen.

# How Hyperframes goes, in her order

```
Claude desktop → Code tab → new session → new empty folder
        │
"install hyperframes"          5 to 10 minutes
        │
a spoken prompt                storyboard comes back first
        │
you approve or change it       cheapest place to fix things
        │
it builds scene by scene       subagents, in parallel
        │
"launch preview"               studio opens in the browser
        │
export → MP4 on your disk
```

- Install takes "five maybe 10 minutes" ([4:02](https://www.youtube.com/watch?v=ncpA7rRk2Is&t=242s)). If the plain version fails, a viewer tip she adopted was "Install Hyperframes opensource video editor" ([57:01](https://www.youtube.com/watch?v=ncpA7rRk2Is&t=3421s)).
- On storyboards: changes made early are "less expensive downstream to fix" ([26:00](https://www.youtube.com/watch?v=ncpA7rRk2Is&t=1560s)). Her Remotion video gives the same advice ([7:31](https://www.youtube.com/watch?v=xrydO6E3fT0&t=451s)).
- For long jobs she prefers the terminal. She found Claude desktop "less stable" for long-running agents ([13:01](https://www.youtube.com/watch?v=ncpA7rRk2Is&t=781s)).

## Her four prompts, as shapes

She reads four prompts aloud. Each ends in an MP4. Here is their shape, not their full text:

1. Beginner ([8:32](https://www.youtube.com/watch?v=ncpA7rRk2Is&t=512s)). An 8-second landscape video on one topic, with one strong animated visual metaphor. It ends "Keep it fast to render", which means no downloads or screenshots.
2. Faceless explainer ([21:30](https://www.youtube.com/watch?v=ncpA7rRk2Is&t=1290s)). It uses the /faceless-explainer workflow, 30 seconds, styled like a "highbudget Netflix investigation", with a hook in the first 3 seconds.
3. Intermediate ([31:00](https://www.youtube.com/watch?v=ncpA7rRk2Is&t=1860s)). It uses /website-to-video to make a 25-second launch video from a URL, capturing "the website's actual colors, typography, UI, and brand feel". ⛔ See the warnings above.
4. Next level ([42:31](https://www.youtube.com/watch?v=ncpA7rRk2Is&t=2551s)). It edits raw talking-head footage. It transcribes, removes false starts and filler, and trims pauses "over.3 seconds" ([43:00](https://www.youtube.com/watch?v=ncpA7rRk2Is&t=2580s)). Then it picks a visual per key idea, keeps one recurring motif, syncs each graphic to the moment it is spoken, and outputs at the footage's own aspect ratio ([45:01](https://www.youtube.com/watch?v=ncpA7rRk2Is&t=2701s)).

# What to try — one step, tonight

This costs plan tokens only. It needs no API key, stays on your Mac and posts nothing.

```
1. make a new empty folder outside ~/Desktop (iCloud)

2. open Claude Code there and type:
   install hyperframes open source video editor
   (wait 5-10 minutes)

3. put 3 PNGs in the folder, rendered from ONE real
   listing PDF (ask Claude to render pages 1, 2 and 5
   with a local tool, and to change nothing)

4. type:
   Create an 8-second vertical 9:16 video. Show these
   three page images exactly as they are, never
   redrawn, never recoloured. Animate only a title,
   the true page count and a slow zoom. No voiceover.
   Keep it fast to render. Show me the storyboard first.

5. launch preview, export the MP4, then compare
   each frame against the PDF yourself. Do not post it.
```

Step 5 is the point. The only thing that decides whether this video can ever be used is whether every page in it is a real page.
